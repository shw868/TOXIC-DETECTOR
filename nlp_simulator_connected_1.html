// how translation works
When a non-English comment is detected, ToxiScan automatically calls the MyMemory Translation API (free, no API key needed) to get an English translation. This translation is shown alongside the toxicity result so you can verify what the comment means — especially useful for script-based languages like Hindi, Tamil, Arabic, and Cyrillic.
Detection uses Unicode block ranges for script-based languages, and vocabulary fingerprints for romanized languages (Hinglish, Spanish, French, German, Portuguese). The model analyzes the original text — not the translation — for accurate toxicity scoring.
